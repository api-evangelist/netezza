# Netezza (IBM Netezza Performance Server)

> IBM Netezza Performance Server is a cloud-native data warehouse and analytics appliance for large-scale SQL analytics and in-database machine learning on structured data. It runs on IBM Cloud, AWS, and Microsoft Azure and within IBM Cloud Pak for Data. Netezza is consumed through SQL over standard database connectivity — the pure-Python nzpy DB-API 2.0 driver, JDBC (nzjdbc) and ODBC drivers, and the nzpyida in-database analytics library — rather than as a public REST API.

## Client libraries

- [nzpy (PyPI)](https://pypi.org/project/nzpy/): Official pure-Python DB-API 2.0 driver — `pip install nzpy`. Source: https://github.com/IBM/nzpy
- [nzpyida (PyPI)](https://pypi.org/project/nzpyida/): Official in-database analytics library — `pip install nzpyida`. Source: https://github.com/IBM/nzpyida
- [Netezza JDBC driver](https://www.ibm.com/docs/en/netezza?topic=dls-installing-configuring-jdbc): Official nzjdbc.jar via IBM Fix Central.
- [Netezza ODBC driver](https://www.ibm.com/docs/en/netezza?topic=icow-configuring-odbc-data-source-driver): Official ODBC driver.
